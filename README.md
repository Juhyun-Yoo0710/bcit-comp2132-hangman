# Hangman

BCIT COMP2132 (JavaScript I) final project — a browser-based Hangman game built with vanilla JavaScript, HTML, and Sass.

**Live demo:** https://juhyun-yoo0710.github.io/bcit-comp2132-hangman/

## Features

- Word list loaded from `data/words.json`
- On-screen letter buttons with keyboard-style interaction
- Hangman illustration that updates with each incorrect guess
- Win/lose states

## Tech

Plain HTML, CSS (compiled from Sass — see `css/style.scss`), and vanilla JavaScript. Open `html/index.html` directly in a browser, or serve the folder with any static file server.
